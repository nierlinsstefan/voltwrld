# Voltworld Elegance

Create a premium, modern e-commerce website for my brand VOLTWRLD. The design should be elegant, minimal, clean, and high-end, using only black, white, and subtle gray colors. Do not use yellow, lightning bolts, energy effects, or overly aggressive graphics.

Use bold modern typography, smooth animations, large product images, clean spacing, and a professional luxury aesthetic.

Include:

* A stylish homepage with a strong VOLTWRLD hero section
* Featured products section
* Shop All page
* Product pages with images, price, description, variants, and Add to Cart button
* Categories for grips, accessories, and other products
* Shopping cart and checkout
* Contact section
* Instagram/social media section
* Clean navigation bar with the VOLTWRLD logo
* Mobile-friendly responsive design

The brand should feel similar in quality and presentation to premium brands such as ODI, but the website must have its own unique identity and design. Make everything look polished, expensive, minimal, and professional. Use subtle black-and-white animations and hover effects, but keep the overall design clean and not cluttered.
